# Terminal Setup & Command Line Knowledge

## Terminal Client Choice
* **Choice:** Windows Terminal with PowerShell.
* **Why:** It is built into Windows, supports multiple tabs, and is highly customizable. It provides a modern experience for managing both local files and remote servers.

## Basic Commands I Learned

| Command | Action |
| :--- | :--- |
| `pwd` | **Print Working Directory:** Shows the path of the folder I am currently in. |
| `ls` | **List:** Shows all files and folders in the current directory. |
| `cd <folder>` | **Change Directory:** Moves me into a different folder. |
| `mkdir <name>`| **Make Directory:** Creates a new folder. |
| `touch <name>`| **Create File:** Creates a new empty file (or `ni` in PowerShell). |
| `clear` | **Clear Screen:** Cleans up the terminal window. |

## Reflection
### What was the most useful command you learned today?
The most useful command I learned is `ls`. Being able to quickly see what is inside a folder without using the File Explorer makes navigating through a project much faster. 

### Why is the terminal important for QA?
The terminal is essential for running automated test suites (like Playwright or Cypress) and checking server logs. It allows for automation and speed that you can't get using just a mouse and a graphical interface.
