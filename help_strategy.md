# Problem-Solving & Help Strategy

## My Approach
* **AI vs. Google:** I prefer using AI for explaining complex errors or generating boilerplate code. I use Google when I need to find documentation for a specific library or see recent discussions on Stack Overflow.
* **When to ask a Colleague:** I decide to ask a colleague if the problem is specific to the Focus Bear codebase that an AI wouldn't know about, or if I have been stuck for more than 30 minutes despite my research.

## Troubleshooting Challenges
* The biggest challenge when troubleshooting alone is "tunnel vision"—getting so focused on one solution that you don't see a simpler alternative. Asking for help provides a fresh perspective.
