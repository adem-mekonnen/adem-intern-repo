# Agile Workflows & Kanban Reflection

## Research & Learning
* **How Kanban works:** It visualizes work on a board so everyone can see the status of every task. It helps manage flow by showing where work is getting stuck.
* **Columns:** 
    * **Backlog:** Tasks to be done later.
    * **In Progress:** What I am working on right now.
    * **Ready for Review:** Tasks I finished and closed (waiting for the bot).
    * **Done:** Approved tasks.
* **Movement:** The person assigned to the task is responsible for moving it as they work on it.
* **WIP Limits:** Limiting "Work In Progress" helps you focus on finishing one thing before starting another, which actually makes the whole team faster.

## My Reflection
* **Overload:** Kanban prevents overload by making it obvious when I have too many tasks "In Progress."
* **Improvement:** I can improve by ensuring I never have more than 2-3 tasks open at once.

## Task Summary
* **Task Tracking:** I can improve tracking by linking my commits directly to the issue numbers so the history is clear.
