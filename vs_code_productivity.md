# VS Code Productivity & Keyboard Shortcuts

## Top 10 Useful Shortcuts (Windows)

### 1. Navigation
| Shortcut | Action | Why it's useful |
| :--- | :--- | :--- |
| `Ctrl + P` | **Quick Open File** | Lets you type a file name to jump straight to it without clicking through folders. |
| `Ctrl + Shift + F` | **Global Search** | Searches for a word or piece of code across every file in the entire project. |
| `Ctrl + B` | **Toggle Sidebar** | Hides or shows the file explorer to give you more screen space for code. |

### 2. Editing
| Shortcut | Action | Why it's useful |
| :--- | :--- | :--- |
| `Alt + Click` / `Ctrl + Alt + Down` | **Multiple Cursors** *(Must-have)* | Lets you type or edit on multiple lines at the exact same time. |
| `Ctrl + D` | **Select Next Occurrence** | Selects the next matching word so you can rename multiple variables at once. |
| `Alt + Up / Down Arrow` | **Move Line** | Moves the current line of code up or down without cutting and pasting. |
| `Ctrl + /` | **Toggle Comment** | Instantly comments out or uncomments a line (great for testing). |

### 3. Debugging
| Shortcut | Action | Why it's useful |
| :--- | :--- | :--- |
| `F5` | **Start / Continue Debugging** | Launches your test or app with the debugger attached. |
| `F9` | **Toggle Breakpoint** | Sets a red stopping point on a line of code to pause execution and inspect variables. |

### 4. Terminal Commands
| Shortcut | Action | Why it's useful |
| :--- | :--- | :--- |
| `Ctrl + \`` *(Backtick)* | **Toggle Terminal** | Opens or hides the integrated terminal at the bottom of VS Code instantly. |

## Reflection

### Which shortcuts do you think will be the most useful in your daily work?
The most useful shortcuts will be **`Ctrl + P` (Quick Open)** and **`Ctrl + D` (Multi-cursor select)**. In a large project like Focus Bear, finding files quickly with `Ctrl + P` saves minutes every hour. Using `Ctrl + D` to edit repetitive test data or rename variables with multiple cursors prevents typos and speeds up refactoring.

### How can keyboard shortcuts improve your productivity?
Keyboard shortcuts keep my hands on the keyboard, which maintains my "flow state" and reduces friction. Every time I have to reach for the mouse to navigate a menu, it breaks concentration. Shortcuts turn multi-step actions into a split-second muscle memory habit.
