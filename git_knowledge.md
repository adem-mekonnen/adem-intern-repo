## Reflection

### Have you used Git before?
Before this internship, I had seen Git used in projects, but I primarily worked through the GitHub web interface. This is my first time setting it up as a professional local development environment.

### What was the most interesting thing you learned about Git today?
The most interesting thing I learned is that Git is "distributed." This means that when I "Clone" my repository to my computer, I actually have the entire history of the project on my own machine, not just the latest version. This allows me to work offline and still see all previous changes.

### Why is Git essential for a QA Intern?
Git allows me to switch between different "Branches" to test new features that are still being built. It also helps me track down exactly when a bug was introduced by looking at the history of changes (using `git blame` or `git log`).
