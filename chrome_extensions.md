# Dev Productivity Chrome Extensions

## Extensions Installed

| Extension | Purpose |
| :--- | :--- |
| **React Developer Tools** | Allows me to inspect the component hierarchy, props, and state of React applications (like the Focus Bear portal). |
| **Redux DevTools** | Essential for debugging state changes if the application uses Redux for state management. It allows for "time-travel" debugging. |
| **JSON Viewer** | Automatically formats raw JSON data from API calls into a readable, collapsible tree structure. |
| **Lighthouse** | Used to audit the performance, accessibility, and SEO of web pages to ensure high quality and speed. |

## Experience & Reflection

### Why did I install these?
As a QA intern, I need to see more than just the visual UI. These tools allow me to verify that the data being sent to the browser is correct, even if it isn't visible on the screen yet. For example, I can use the JSON Viewer to check if a bug is in the data from the server or just how the page is displaying it.

### What was the most useful thing I learned?
I learned that "Lighthouse" isn't just about speed; it also checks for "Accessibility." This is very important for Focus Bear’s mission of being inclusive for neurodivergent users who might have specific sensory or visual needs. Ensuring the app meets accessibility standards is a key part of the QA process.
