# Cyber Security Guidelines Reflection

## Research & Learning
* **Remote Threats:** Common threats include phishing emails, malware, and unsecured public Wi-Fi networks.
* **Device Security:** Best practices include keeping the operating system updated, using an antivirus, and avoiding suspicious downloads.
* **Locking Devices:** Locking my computer when away from the desk prevents unauthorized physical access to sensitive company code and data.
* **Phishing:** If I see a suspicious link or email, I will not click it. I will verify the sender and report it to a supervisor if it looks like a targeted attack.
* **Passwords & 2FA:** A strong password is long and unique. Using a password manager (like Bitwarden or 1Password) is safer than reusing passwords. Two-Factor Authentication (2FA) adds a vital second layer of security in case a password is stolen.

## My Reflection
* **Current Measures:** I currently use unique passwords for main accounts. I can improve by enabling 2FA on every service that supports it.
* **Breach Response:** If I suspect my account has been compromised, I will immediately change my password from a clean device and notify my supervisor via Discord or the CEO via the emergency contact number.

## Task Summary
* **Account Security:** I have ensured my main work accounts have strong, unique passwords.
* **2FA:** I have enabled 2FA on my GitHub account.
* **Auto-Lock:** I have set my computer/phone to automatically lock after 5 minutes of inactivity.
* **New Habit:** My new habit will be to never use public Wi-Fi for work without using a secure VPN connection.
